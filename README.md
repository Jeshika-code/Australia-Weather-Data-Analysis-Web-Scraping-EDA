# Australia-Weather-Data-Analysis-Web-Scraping-EDA
An end-to-end Python data analysis project that scrapes weather data for Australian cities, cleans and transforms the dataset, and performs exploratory data analysis using Pandas and Matplotlib.

# Project Overview
The main objectives of this project were to:

- Scrape weather data for Australian cities
- Build a structured dataset from unstructured web content
- Clean and validate the scraped data
- Perform exploratory data analysis (EDA)
- Identify the hottest and coldest cities
- Analyze temperature distribution
- Categorize cities based on temperature ranges
- Create visualizations to communicate findings


## Tools & Technologies

**Python**
**Pandas** – Data cleaning, transformation and analysis
**Requests** – Sending HTTP requests
**BeautifulSoup** – Web scraping and HTML parsing
**Matplotlib** – Data visualization
**Jupyter Notebook** – Analysis environment
